# About

I'm Munkherdene. This blog is where I write down how computers actually work, the way I learned it: by building something small and following it all the way down.

The current series starts with one question: how do a few letters of code turn into something a CPU runs? **Season 1** is about Cecile, a small interpreted language I wrote in Rust — the lexer, the parser, the bytecode, the virtual machine. **Season 2** is about Mon, a compiler written in Go with Mongolian keywords, followed down through assembly, syscalls, the debugger, linking and loading.

Every post tries to explain one layer properly, with real code and pictures, and to stay honest about what I didn't understand at the time.

Posts are written in English; some are also translated into Mongolian.

You can follow new posts through [RSS](/rss.xml).
